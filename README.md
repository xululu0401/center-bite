# 正中心那一口

上次那块泡了多久刚好入味，这次换了大小和形状（长方块、圆柱/长条、球/蛋），要泡多久味道才进到正中心。按菲克扩散（分离变量的乘积解）换算：用上次那一次反推渗透快慢，再算这次要泡多久；给出改时长、整块等比切小、只切薄最薄那边几种改法，以及等比例变大变小、同样最薄一边换个形状、换一个「入味」标准的对照。

- 在线体验：https://xululu0401.github.io/center-bite/
- 单文件页面 `index.html` + `core.js`（计算）+ `ui.js`（界面），不联网，输入只存在浏览器本机。
- 测试：`node --test tests/core.test.cjs`；独立参考实现 `tests/ref.py`（自算贝塞尔零点 + 线性二分 + 有限差分抽查）；注入测试 `node tests/inject.cjs`。
- 只换算时间，不判断咸淡口味，也不做食品安全判断；默认数字是虚构示例。
